# 拾光 · 家庭星海设计与实现

2026-10-21。此方案针对真实 Vue 应用，静态 public/preview 不作为业务入口。

## 产品与体验

首页是一家人共同点亮的星海。记忆按发生日期归档；珍藏按后端星海索引的封存日期归档，开启日期仍只决定阅读权限。深靛夜空承载按年月日身份区分的彩色星光，记忆与珍藏使用柔和暖色；普通内容页、阅读与编辑使用暖白纸面和暖棕正文。避免冷硬金属、满屏玻璃和未经定义的幸福指数。

首页入口常驻“记录这一刻”“封存一封信”“回忆相册”。星海以既有年份→月份→日期→内容结构探索，同时提供时间文字列表、关键词搜索、缩放、暂停、轻量模式与相册退路。装饰尘埃不计入业务数量，稀疏家庭不生成假记忆。

## 信息架构与功能保留清单

| 入口 | 路由 | 保留能力 |
| --- | --- | --- |
| 星海首页 | `/` | 原星海层级、搜索、时间导航、记忆阅读与珍藏跳转；新增记忆/珍藏入口与成功入星仪式 |
| 回忆相册 | `/memories` | 原首页全部列表、舒展/标准/紧凑、本地偏好、PC 分页、移动增量加载、喜欢、回应、媒体预览、空与错误状态 |
| 时光轴 | `/timeline` | 原星海/相册双模式与个人偏好、年份分组、搜索与筛选 |
| 珍藏 | `/vault` | 信件列表、筛选、开启状态、倒计时、创建表单、详情；共享创建组件不减少字段 |
| 家人 | `/family` | 成员、家庭管理、邀请码、纪念日与 PRIVATE/FAMILY/SPECIFIC、管理权限 |
| 详情 | 原 `/memories/:id`、`/capsules/:id` | 原媒体、声音、喜欢、回应、删除/管理与服务端权限；返回来源可识别 |
| 登录/初始化 | 原路径 | 原认证守卫、登录 redirect、创建/加入家庭 |

不删除旧首页，迁移为相册路由。五个导航目的地始终可达。普通页面保留顶部/移动底部导航；星海首页使用融入画布左上角的页面菜单，不再出现独立横向顶栏和重复底栏。当前家庭、账号菜单、退出、全局搜索保留。全局标题搜索进入星海，覆盖记忆与珍藏；时光轴原本的局部搜索保留。每页任务仍由页面自身承担，不把所有操作强制塞进星海。

## 视觉规范

- 页面：暖白 `#FFFAF5`，纸面 `#FFFDF9`，正文 `#332E2B`，次级文字 `#70543E`。
- 品牌：珊瑚 `#E76F51`；常规白字按钮用深珊瑚 `#BF4C36`；浅选中底 `#FDF0EC`。
- 夜空：深靛 `#0B101B`，暖白标题、琥珀重点、桃色次级星光。保留空间深度，不把整幅星海染成棕色。
- 字号：正文/表单 16px，导航/按钮 14–15px，必要元信息 13px；标题 28–32px。输入聚焦使用与形状一致的细边框，避免醒目外扩双环。
- 记忆是有真实 ID 的星点；珍藏使用独立的暖色星点与珍藏图标区分。标题、图标及可读列表共同说明含义，不只靠颜色。
- 编辑浮层沿用完整字段：标题、正文、最多九个照片或视频、独立声音、发生日期、地点、标签；珍藏保留标题、收信人、正文、开启日期。成功前不丢失失败重试内容。

## 创建与入星状态机

1. 在真实表单中上传并提交；保存中防止重复操作，错误保留输入。
2. 仅在 API 成功返回真实业务 ID 后发布轻量成功回执：家庭、来源类型、ID、标题、归档日期、编辑面板屏幕位置。不把正文复制到星海索引或事件缓存。
3. 刷新星海概要，在有界分页内核对新索引的 sourceType/sourceId。复用真实索引的日期与位置，不伪造 indexId，不以开启日期代替封存日期。
4. 增量更新场景，不重新创建 WebGL 渲染器。若目标不在当前视野，短暂靠近所属星群；用户拖动能中断镜头。
5. 从原编辑面板位置凝聚暖光，沿柔和弧线飞入真实星点，落定时一圈小光晕。约 1.4 秒，珍藏同样以暖色星体归位。每次成功只消费一次回执。
6. 提供“查看刚刚的记忆/珍藏”，不自动展示未开启珍藏正文。
7. 索引尚不可见或刷新失败时，明确显示“已经保存，星图暂未更新”，保留详情入口和重试。不得让成功保存被误报为保存失败，也不重复 POST。

成功仪式仅用于真实保存。自动化验收使用测试响应验证成功/失败分支，不在用户家庭中插入测试回忆。减少动态偏好下省略飞行和镜头运动，直接给定位与文本反馈；后台或卸载取消未完成动画和请求。

## 页面设计

### 星海首页

左上角品牌展开页面与账号菜单，五个目的地均保留。右侧“时光碎片”统一承担标题搜索、年月日路径、下一层选择、记忆/珍藏筛选、分页和新增记忆/封存珍藏；去掉独立时间导航、重复搜索和外置新增托盘。手机使用可收起面板，新增动作固定在面板底部，视角控制在面板关闭后显示。错误和不支持 WebGL 时，页面菜单中的相册入口仍可操作。

### 相册、时光轴与详情

相册沿用真实分页和密度能力；原卡片与媒体浏览不以静态稿替换。照片、正文、作者与发生日期为阅读主线。时光轴仍保留双模式。记忆阅读可在星海展开，完整故事和回应继续走详情页；珍藏详情严格依赖接口 opened 状态。

### 珍藏和家人

珍藏保持信笺与倒计时，统一共享封存表单，使首页和珍藏页提交行为一致。家人页保留家庭信息、成员、邀请和纪念日表单；不调整权限、统计口径或新增虚构在线状态。共用顶部导航和纸面主题，使阅读页面与星海保持品牌一致。

## 技术边界与验证

- 不改变认证、数据表、接口参数、索引算法与既有权限。额外读取索引有请求上限与取消机制。
- 保留 scene/cache/preloader；创建后只更新概要和真实新增索引。来源 ID 相同但类型不同不能误匹配。
- 场景后台暂停、减少动态、轻量模式、资源 dispose 与事件清理保留。
- 检查 PC、平板、375px 手机；可键盘访问新增/返回/相册与弹窗；导航和提交区避开安全区。
- 运行构建、创建回执/索引匹配测试；真实只读流程检查首页、相册、时光轴、珍藏、家人和两种表单。
- 测试与运行结果在实现后补记，不把设计目标描述为已经完成。

## 路径与统一碎片查看（按后续反馈补充）

- 悬停/点击年月日时显示完整祖先链以及直接下一层时间标签；曲线继续呈现完整真实子树。空节点不生成连接，不靠每颗星旁的独立弹框解释内容。
- PC 右侧固定“时光碎片”，手机为可收起的底部面板。它展示所选时间范围的索引标题、日期、来源类型与下一层入口，每页八项，可切换“全部/记忆/珍藏”。
- 点击内容星点只选中并更新统一面板；用户再点击面板中的项目时，才展开记忆阅读或进入珍藏详情。
- 碎片列表直接复用当前星海会话的 UniversePreloader、搜索页和创建增量索引；同一缓存已完整时，年月日浏览、悬停和来源类型切换不发重复索引请求。读取详情时仍以业务接口权限为准。
- 仅新建或未加载完整的年份需要补取。创建索引查询先检查缓存，再最多读取日期首页、日期末页和一个标题搜索页；没有找到则明确提示稍后刷新，不伪造星点。
- 成功回执保留三十秒，避免从其他页面很久以后进入首页时播放过期仪式。

## 一体化工作区与交互校正（2026-10-21）

- 面板数量使用“共 N 项”，不显示缓存、索引、载入批次等工程信息。
- 年份按年份身份生成随机色；月份按月份数字生成，同为二月跨年同色；日期按日号生成，同为二号跨月同色。记忆与珍藏各自按来源类型和业务 ID 从暖色色域生成稳定随机色，不随悬停和重绘变色。
- 空闲只保留基础年份定位；悬停临时显示完整祖先链与子路径；移开恢复已点击固定的路径，未固定则清除子标签和临时线。点击固定，重复点击同一星点、点击空白、Esc 可取消固定。
- 面板内悬停只预览星图，不自动钻入层级；离开面板、关闭面板、失焦、切到后台均清除临时状态。菜单的 Esc 只关闭菜单，不误清除星海选择。
- 类型筛选同时约束列表、时间节点、星点命中与连线，零结果不保留不可操作的年月按钮。清除标题搜索时保留类型选择。
- 新增了颜色身份、暖色范围、交互状态、真实 Three.js 连线模型和端点颜色继承测试。十八项测试全部通过；已实测跨年八月同色、跨年七号同色、移开清理、固定日期恢复、空白取消、搜索零结果和缓存无重复请求。

- 手机端将搜索与两个新增动作固定在同一面板，320px 与 375px 实测无横向溢出，菜单和面板入口不重叠；原记忆的照片/视频/声音/日期/地点/标签字段，以及珍藏的标题/收信人/正文/开启日期均保留。测试只打开与关闭表单，没有提交真实数据。


## 星海生命感与入星叙事（2026-10-21）

- 默认播放缓慢自转；悬停、拖动与固定选中时停止自转，保留星点呼吸和连线流光。暂停、系统减少动态与页面隐藏均受尊重。
- 记忆与珍藏是主要视觉节点：暖色各异、独立相位的闪烁；悬停增亮、选中放大，背景星尘适度退后。连线以窄亮段沿真实关系曲线流动。
- 指向具体内容时，星旁出现一个标题、日期、类型提示；时光碎片只呈现该内容。年月日仍聚合相应时间段。面板行预览不改变列表范围，避免悬停导致列表自我裁切。
- 首页新增记忆和封存珍藏改为同一区域的暖暗色嵌入编辑器，无全屏遮罩。桌面在右侧，手机为底部编辑区；关闭保留草稿，失败保留内容与已上传文件缓存；原字段、上传、校验与真实 API 保留。普通页面继续使用原对话框。
- 仅 API 成功后发布入星事件：编辑器轮廓收拢成星，等待真实索引定位，流星落到实际投影点，屏幕涟漪与三维星点波动同时扩散，镜头随后推近并固定选中新星，面板只展示这一项。镜头取景让开桌面侧栏及手机底部面板。
- 找不到索引时不制造假星；显示已保存和更新星图入口。筛选排除新星时告知当前筛选；暂停、减少动态、隐藏页面时直接完成状态更新。可以跳过动画，离开页面会清理动画、监听器和计时器。
- 动画事件只携带内容标识、日期及编辑器几何边界，不携带正文或媒体内容。开发验证拦截保存请求，不向真实家庭数据添加测试内容。

## 分支标签、星海波动与紧凑工具（2026-10-21）

- 年份悬停或点击展示整棵分支的年、全部月份、全部日期；月份展示其日期和祖先路径，叶节点只保留祖先年月日。临时悬停与已选分支同时存在时，标签与连线覆盖范围一致。默认全景保留年份标签。
- 标签布局避让所有可见星点、已选星点的光晕、其他标签以及主要界面区域；标签自身可以悬停和点击，不盖在星点上。
- 去掉入星后的屏幕圆环。使用随距离向外传播并衰减的波场，驱动星点和星尘的位置、连线的顶点与切线、星云画面的折射。CPU 投影使用同一波场，使标签和命中位置跟随实际波动；暂停、减少动态和隐藏页面不继续播放波动。
- 时光碎片隐藏滚动条，但保留滚轮、触摸和键盘浏览。搜索收为标题栏图标，点击展开并聚焦搜索框。新增收为一个加号，悬停或点击展开新增记忆、封存珍藏，可用 Escape 或外部点击关闭；所有业务字段和编辑流程保留。
- 本轮增加完整日期分支、标签避让与波场传播/衰减测试。浏览器工具发生连接错误，本轮视觉改动尚未完成实页截图复核。


## 沿线日期和镜头推进修正

- 取消每帧全局避让找空位：年月日改为实际贝塞尔连线上的固定参数锚点，随曲线投影和星海波动连续移动，不会自行换边、远离路径。没有展开连线的年份使用固定近旁位置。
- 修复记忆、珍藏星点点击只选中而不推进的问题；点击主动推进到目标，时光碎片仍仅显示该项。面板中的翻阅业务保持原有入口。
- 旧视角是透视相机 zoom=1 加自动范围计算，并非固定放大倍数。默认全景改为适配距离基础上的 1.25 倍；年月日分别增加 1.3/1.5/1.7 倍的取景力度。内容点击按当前距离约减半推进，近距离不向后退。
- 点精灵大小随镜头接近适度增加（上限 2.2），避免相机已经推进、星点却仍维持相同屏幕尺寸。镜头动画期间提高标签投影更新频率。
- 浏览器工具仍发生连接错误；本轮使用构建、曲线锚点和镜头距离测试核对，尚未做最新实页视觉复核。


### 推进幅度回调

用户实页截图反馈内容推进过大。将每次内容推进限定为当前镜头距离最多缩短 18%，设置 70 单位的近景距离保护（已经更近时不后退）；取景半径由 7 改为 20。年月日取景系数回调为 1.15/1.25/1.35。星点随镜头增大的上限由 2.2 改为 1.3，选中尺寸增幅收敛，并将点精灵限制在 48 CSS 像素以内。默认全景 1.25 保持不变。


## 星点与时光碎片的光粒关联

- 去掉记忆和珍藏星点旁的标题弹框，内容统一在时光碎片查看。
- 悬停内容星点，播放一次 520ms 的短弧光粒，落在对应卡片上后边缘轻亮；点击保持选中关联和温和镜头推进。目标不变不重复发射，移出临时预览时取消尚未完成的传递。
- 面板收起时光粒先落向时光碎片入口；点击所选星点时，传递结束后展开对应单项内容。手机使用点击流程。
- 卡片悬停、键盘聚焦反向传递光粒到对应星点；卡片原有的点击阅读或跳转功能保留。用一次轻微星点呼吸作为抵达反馈，不绘制持续跨屏连线。

## 流星抵达与集合语义

- 关联传递统一升级为 780ms 的流星：明亮星核、约 140px 的动态渐隐拖尾与柔光；拖尾只覆盖流星身后的一段弧线，不留下跨屏常驻连线。
- 面板改为已送达的独立状态：传递时保留上一份数据，显示简短送达提示；只有当前流星抵达后才切换对应内容并触发星海波动。快速切换取消旧流星，过期抵达不能覆盖新范围。
- 记忆和珍藏抵达后显示单项；年、月、日抵达后显示该时间范围的集合、总数与整段时光提示，不默认选中集合中的任意条目。原筛选、分页、阅读入口保留。
