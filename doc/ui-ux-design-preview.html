A QUIETER DESIGN SYSTEM

温暖，也有清楚的秩序。

同一套颜色、字体、间距与反馈，贯穿每一页。

主体色调，继续保留。

动作有主次

每个状态，同时给出图标与文字。

细节有一致的尺度

  • 正文 16px，元信息 13px，操作 15px。
  • 按钮/输入圆角 12px，卡片 16px，弹窗 24px。
  • 间距围绕 8 / 16 / 24 / 32 / 40px 建立。
  • 主动作白字对比度 4.88:1。
  • 44px 操作热区，键盘焦点清楚可见。
  • 局部过渡 160–220ms，尊重减少动态偏好。
