# 拾光 · 全站视觉与交互统一方案

日期：2026-10-21。状态：设计基线；第一轮代码改造已实施，实页视觉验收待完成。

本方案根据当前真实 Vue 页面、公共布局和组件梳理，不以旧静态预览为依据。延续已确定的温暖、克制、有空间感的星海气质，并修订此前“星海深色、其他页面暖白”的分离方式。初次方案阶段只新增文档；后续经用户确认已进入实施，实际记录见文末。

## 1. 设计结论

全站采用同一套「深靛环境、暖色文字、安静阅读层」：进入相册、珍藏或家人页时，像从星海走近其中一段故事。页面背景、菜单、操作和返回行为连续，内容的组织方式随任务变化。

星海承担空间探索；相册承担图片浏览；时光轴承担时间检索；珍藏承担等待与阅读；家人承担成员、邀请和纪念日操作。把这些任务都塞进星海的右侧面板，会降低效率，因此各页保持独立的内容布局。

统一的重点依次是：公共外壳 → 操作规则 → 内容排版 → 状态反馈 → 动效细节。流星和星屑只在内容关联、真实保存等有意义的时刻出现。

## 2. 当前割裂的实际来源

| 实际位置 | 当前情况 | 调整方向 |
| --- | --- | --- |
| `AppLayout.vue` | 星海使用左上轻菜单；其他页使用横向顶栏、账号圆钮和移动底栏 | 统一品牌菜单、当前位置、账号和页面导航的结构与位置 |
| `/memories`、`MemoryCard.vue` | 暖白底、大欢迎区、白色卡片、珊瑚按钮，媒体上叠多层信息 | 改为暖暗色内容区，收小欢迎区，让照片和标题优先 |
| `/timeline` | 星海/经典双模式共存；经典页仍是白底和横向年份按钮 | 两种模式共享暗色外壳，时间筛选采用统一控件 |
| `/vault` | 棕色大倒计时区与白色信件卡混用 | 同一环境中区分封存、可读状态，收敛倒计时的视觉重量 |
| `/family` | 暖白成员卡、多处邀请入口和彩色功能块 | 聚合相同操作，区分家庭介绍、成员、纪念日与管理 |
| 两类详情页 | 大块白底、棕色信封头、不同的返回方式 | 统一阅读层、返回来源和媒体控制 |
| 表单、确认框、提示 | 首页已是嵌入暖暗色编辑；其他页仍有白色弹框、较强焦点圈 | 复用同一编辑、对话框、焦点和状态规范 |

以上是代码结构核对结果；本轮未完成浏览器实页视觉审查。

## 3. 不改变的产品与业务边界

- 五个主目的地仍是星海、回忆、时光轴、珍藏、家人；原路由和认证跳转保留。
- 相册保留舒展/标准/紧凑及偏好记忆、桌面分页、移动增量加载、媒体预览、喜欢和回应。
- 时光轴保留经典与星海两种模式、模式偏好、年份筛选、搜索及既有时间分组。
- 珍藏保留创建、列表状态筛选、收信人、封存时间、开启时间、倒计时和详情。是否可读仍以服务端 `opened` 状态为准；视觉效果不提前暴露封存正文。
- 家人页保留现有成员展示、邀请生成与复制、有效期、纪念日新增/编辑/删除、每年重复、备注和 `PRIVATE/FAMILY/SPECIFIC` 可见范围。权限与接口语义保持不变。
- 新增记忆保留标题、正文、照片/视频、独立声音、发生日期、地点、标签、上传进度、失败保留和重试能力；珍藏保留全部现有字段。
- 已确认的星海规则继续生效：默认碎片区为空、悬停不推进、点击固定、同目标点击不重播流星、年份完整显示、年月日表示集合、实际送达后才显示内容。
- 家庭足迹地图目前是占位能力，方案不把它描述为已经实现的地图，也不在这一轮扩张业务范围。

## 4. 全站公共外壳

### 4.1 菜单与位置

所有页面沿用左上角「拾光 + 家庭名 + 展开箭头」入口。菜单内部统一显示五个目的地、当前位置、当前账号和退出入口；主导航不再出现两套不同的样式和命名。

- 桌面：品牌区域在同一坐标，页面标题从相同的内容基线开始；内容滚动时品牌行可保持可达。菜单展开用同一暖暗色浮层和当前项标记。
- 星海：保留画布铺满、品牌菜单轻叠加的结构；时光碎片内的新增、搜索继续保留，尊重已经确定的操作位置。
- 内容页：使用相同品牌入口，工具放在本页标题栏右侧。新增和搜索沿用星海的图标、展开方式及间距，不另加一组重复的大按钮。
- 手机：沿用同一个品牌菜单和当前页名称，不再在其他页面突然出现另一套主导航。页面底部只在编辑、发送等需要时承载当前任务的操作，不承担第二套全站导航。
- 详情：返回入口同时说明来源，例如「返回回忆」「返回时光轴」「返回星海」。菜单仍可跨页，不把返回变成唯一出路。

导航不依赖 hover：触摸、键盘均可展开；Escape 先关闭当前最上层浮层，关闭后恢复触发按钮的焦点。

### 4.2 页面骨架

内容页统一四层结构：品牌入口 → 标题与简短说明 → 轻工具栏 → 主内容。去掉占首屏过多的装饰性欢迎横幅和英文眉题。标题与正文之间留出明确呼吸空间，不用大面积空白制造“高级感”。

桌面内容最大宽度建议 1280px，主要边距 32px；平板 24px；手机 16px。长文阅读列另限宽，约 680–760px。组件间距使用 8、12、16、24、32 的固定序列。

## 5. 视觉规范

| 层级 | 建议色值 | 使用范围 |
| --- | --- | --- |
| 全站环境 | `#0B101B` | 页面底色，与星海空间连续 |
| 普通内容层 | `#171B25` | 卡片、列表、轻工具区 |
| 阅读与编辑层 | `#1D202B` | 正文、输入、编辑区域 |
| 浮层 | `#24222D` | 下拉、菜单、短对话框 |
| 标题与正文 | `#F0E4D2` | 暖白文字 |
| 次级信息 | `#B5AA9B` | 日期、作者、说明 |
| 辅助文字 | `#A59C90` | 合理字号下的提示、占位说明 |
| 主要操作 | `#D2AC7D` 配 `#211C17` | 保存、确认等明确主操作 |
| 情绪点缀 | 柔和桃色、铜色 | 喜欢、珍藏状态、少量强调 |

主文字/普通内容层的理论对比度约 13.72:1，次级文字约 7.53:1，辅助文字/阅读层约 6.00:1，主要按钮文字约 7.99:1。半透明叠加、照片背景和实际状态仍需实页复核，不能直接沿用这些比值。

具体约束：

- 普通页只保留极淡、静止的星尘和暖光背景，正文和照片下不播放粒子；全站同时只运行当前可见页面需要的场景。
- 照片使用中性深灰承托，图片本身不加暖色滤镜；星海色彩不会改变家庭照片的颜色。
- 大标题只在页面标题使用宋体气质，卡片标题、按钮、表单和正文使用清楚的系统字体。正文 16px、行高约 1.8–1.9；操作 13–14px；必要元信息原则上不少于 12px。
- 工具圆角约 10px，内容卡片约 14px，编辑区域约 18px。统一细边与少量明度差，不使用多层粗描边、错位双边框或大面积紫色玻璃。
- 状态同时用文字/图标表达。暖色随机星点不等于成功、失败或权限标记。

## 6. 每个页面如何调整

### 6.1 回忆相册 `/memories`

定位：从星海进入可以安静翻看的家庭相册。

- 顶部收为「回忆 + 数量 + 一句说明」，右侧为新增与本页搜索。取消大问候横幅占位。
- 第二行是年份/类型等已有筛选入口和密度切换；筛选按需展开，当前条件用短摘要表达。搜索在本页完成，不意外把用户送回首页。
- 保留三种密度。桌面大屏目标为约 3/4/5 列，按真实可用宽度收敛；手机默认易读单列，紧凑模式可使用双列媒体布局，操作触达不能因此变小。
- 卡片按照片、标题、作者/发生日期、喜欢/回应组织。媒体数量只在有多媒体时出现，地点与时间不再同时压在照片、正文及页脚三处。
- 点击图片仍打开媒体预览；点击标题或故事区进入详情；喜欢只完成喜欢，不触发路由。这三个区域的行为和焦点必须明确。
- 文字、声音记忆使用相应内容摘要，不用巨大的空图片框伪装照片卡。
- 桌面保留分页，手机保留增量加载和失败后的明确重试入口。离开详情再返回，恢复密度、页码、筛选和滚动位置。

### 6.2 时光轴 `/timeline`

定位：回答“那一年、那个月发生了什么”。

- 时间列表用轻时间线、清楚的年月标题和紧凑内容行，不使用每条都很厚的大卡片。
- 类型、年份等工具采用同一筛选控件；当前时间范围可读，较长年份集合不横向堆满按钮。
- 保留「时间列表 / 星海」模式和个人偏好。已有偏好继续遵从；无偏好时建议默认时间列表，让该页与首页各有侧重，这属于拟调整的默认行为。
- 星海模式复用同一个 `StarTimeline` 及相同控件，不维护第二套颜色、动画或交互规则。
- 列表条目点击阅读；鼠标经过只轻亮，不推进镜头、不切换页面。手机时间标题可随滚动提示当前位置。
- 现有经典时间请求有 `size:50` 的读取范围，设计不能把这 50 条称为完整历史。若需要完整翻阅，实施时另核对接口分页能力，不用视觉改造掩盖数据范围。

### 6.3 珍藏 `/vault`

定位：一处温柔、有秩序的信件收藏处。

- 标题、数量和「封存珍藏」入口沿用公共工具位置；封存表单与首页共享同一组件。
- 下一封来信改成适度突出的横向摘要：标题、收信人、开启日期、剩余天数。收小目前很重的倒计时区，避免倒计时压过信件。
- 「所有状态 / 待开启 / 已开启」采用筛选菜单，状态配图标与文字；已开启和待开启使用同一张卡片结构。
- 待开启卡显示封存状态、收信人、约定日期；正文不可见。已开启卡才显示后端允许的摘要。
- 点击可进入封存信息或信件阅读；卡片轻亮，不在 hover 时模拟解封。

### 6.4 家人 `/family`

定位：家庭介绍与共同生活的管理空间。

- 上部为紧凑家庭介绍、已有统计和一个明确邀请入口，不再多处重复同一邀请动作。
- 主区展示成员，头像和称呼为主，管理员身份为次；不使用各自不同颜色的大功能模块。
- 纪念日做成清楚的日期列表：名称、日期/下次日期、每年重复、可见范围，编辑与删除放在同一条目的操作区域。
- 桌面可用成员主栏 + 纪念日副栏；手机依次为介绍、成员、纪念日，所有操作可通过触摸完成。
- 邀请内容使用统一暖暗色短浮层，清楚显示邀请码、有效期和复制状态。
- 纪念日编辑使用统一编辑层。选“指定成员”时就地展开成员选择，默认仅自己可见的语义保持不变。
- 足迹占位区域保持真实状态并降低视觉重量，不画虚构地点和路线。

### 6.5 记忆详情 `/memories/:id`

定位：阅读一段故事，而不是另一块仪表盘。

- 顶部为返回来源、标题、作者、发生日期；地点和标签在同一区域展示，减少重复信息。
- 媒体在中性深灰画布中显示，保留原比例和“完整查看”；多媒体缩略图、视频控制、移动手势沿用统一视觉。
- 正文使用限宽阅读列。大屏可媒体与文字分区，竖长照片或长故事则自然纵向排列，不强制所有内容等高。
- 喜欢与回应贴近内容底部，回应表单与全站输入规范一致。发送错误保留文字，成功后就地更新记录。
- 返回恢复原来的列表位置或星海选择，不把返回当作再次进入首页，也不重播流星或成功仪式。

### 6.6 珍藏详情 `/capsules/:id`

- 使用同一阅读背景和字重，收敛目前的大棕色封面、白色信纸和强黄色图标。
- 封存状态优先展示标题、收信人、封存时间、开启日期及剩余天数；不显示不可读正文。
- 可读时以暖暗色信笺、适当留白和长文行距呈现。阅读优先，不用持续漂浮动画干扰文字。
- 返回到实际来源，包括珍藏列表、首页星海或时光轴。外部直接打开时提供清楚的默认退路。

### 6.7 登录与创建/加入家庭

- 延续相同深靛底、暖光点缀和品牌标题，认证表单使用与应用相同的输入、错误和按钮。
- 登录仍遵从原 redirect；创建/加入家庭仍保留名称、描述、邀请码和称呼等现有字段。
- 使用单个清楚的操作区，不把登录做成需要等待粒子动画才能填写的展示页。

## 7. 菜单、按钮和控件统一规则

| 控件 | 全站行为 |
| --- | --- |
| 主按钮 | 一个区域一个主要动作；暖色实底、深色文字，hover 轻微明度变化，不大幅跳动 |
| 次按钮 | 低对比底或细边，取消、返回、筛选等任务表达清楚 |
| 图标按钮 | 桌面按任务紧凑排列，实际点击区不小于 40px；手机不小于 44px；提供名称和键盘焦点 |
| 菜单与下拉 | 复用暖暗色自定义列表、勾选、方向键、Enter、Escape 和外部关闭；选择后位置稳定 |
| 筛选 | 当前条件摘要可见，工具按需展开；切换类型保留有效日期范围，清空和无结果有明确反馈 |
| 搜索 | 本页工具负责本页搜索，提交后显示关键词、结果数和清除入口；跨页搜索另明确标为全站搜索，避免同名搜索行为不同 |
| 输入与文本域 | 统一字号、内边距、边框；焦点清楚但不外扩发亮；错误在字段附近显示 |
| 日期控件 | 关闭状态、文本格式和外围样式统一；优先保证手机选择效率。若系统日期弹层仍造成明显割裂，再采用可访问日期面板，不为统一而牺牲可靠性 |
| 开关、单选与多选 | 选择反馈及时，文字说明保留；不将权限选项改成只靠颜色的图标 |
| 分页、加载更多 | 有范围和总数，不让无效页出现空白；翻页清除旧临时预览，返回时恢复用户位置 |
| 加载、空与错误 | 骨架与真实布局同尺寸；空状态给相关操作；失败区有重试，局部失败不抹掉整个页面 |

图标统一沿用现有 Lucide。密度选择、阅读操作和危险操作语义明确，不把所有控制都藏成无文字的小点。

## 8. 编辑、弹出层与反馈

- 新增记忆、封存珍藏、编辑纪念日采用同一编辑表面与提交规则。桌面从页面侧边展开；手机使用避开安全区、可随键盘工作的底部/整页编辑层。每页根据可用空间选择呈现位置，字段和操作顺序一致。
- 短任务如邀请码、账号菜单使用短浮层；删除确认仍是明确的确认对话框，保留“保留/取消”和危险操作，不做星屑式消失。
- 媒体预览沿用现有深色全屏浏览器，统一顶部数量、关闭、上一张/下一张、触摸与键盘控制。
- 单次提交期间避免重复提交；上传进度留在编辑区，失败保留草稿与可复用上传结果。
- 保存到服务端成功后才能出现成功反馈。星海页沿用既定入星仪式；其他页就地更新相应列表，给短暂暖光确认及“去星海查看”入口，不强迫跳页，不在后台启动一个星海场景只为播放仪式。
- 提示统一位置和语气，成功通常短暂消退，错误保留恢复入口；保存、加载、权限错误不使用同一种泛化文案。

## 9. 动效与页面衔接

| 场景 | 建议节奏 | 规则 |
| --- | --- | --- |
| 菜单、筛选展开 | 160–220ms | 小幅淡入，位置固定 |
| 按钮 hover/press | 120–180ms | 明度、细边和很轻的按压 |
| 普通卡片反馈 | 160–220ms | 温和高亮，不播放流星 |
| 页面切换 | 180–240ms | 共同背景、内容淡入淡出；不重复放大整个页面 |
| 编辑层 | 220–280ms | 小幅进入，尊重减少动态 |
| 星海到碎片 | 沿用现有专属节奏 | 流星、沿途波动、抵达后的星屑汇聚 |
| 内容阅读 | 稳定为主 | 不持续闪烁，不重播聚合动画 |
